📖 Fairness Metrics Explained

Understanding the key fairness metrics used in this analysis.

1. Statistical Parity Difference (SPD)

📌 What It Measures

SPD measures the difference in positive outcome rates between privileged and unprivileged groups.

Formula: SPD = P(Y=1|Unprivileged) - P(Y=1|Privileged)

✅ Fair Threshold

SPD is considered FAIR when its absolute value is less than 0.10 (10% difference)

This means ≤10% difference in selection rates between groups

📊 Interpretation

SPD = 0: Perfect equality

|SPD| < 0.10: Fair (acceptable difference)

|SPD| ≥ 0.10: Biased (significant disparity)

🎯 Example

If Males have 50% selection rate and Females have 45%, SPD = -0.05 (Fair)

If Males have 60% and Females have 40%, SPD = -0.20 (Biased)

Key Terms: P(Y=1) = Probability of positive outcome | Privileged group = typically the historically favored group | Unprivileged group = historically disadvantaged group

2. Disparate Impact Index (DI)

📌 What It Measures

DI is the ratio of selection rates between unprivileged and privileged groups.

Formula: DI = P(Y=1|Unprivileged) / P(Y=1|Privileged)

✅ Fair Threshold

DI is considered FAIR when it falls in the range 0.80 - 1.25

Also known as the "80% rule" in employment discrimination law

📊 Interpretation

DI = 1.0: Perfect equality

0.80 ≤ DI ≤ 1.25: Fair (acceptable disparity ratio)

DI < 0.80 or DI > 1.25: Biased (adverse impact)

🎯 Example

If Females: 48% and Males: 60%, DI = 0.48/0.60 = 0.80 (Fair)

If Females: 30% and Males: 70%, DI = 0.30/0.70 = 0.43 (Biased)

Key Terms: Ratio = How many times more/less likely | Fair range = Legal threshold based on 80% rule | Confidence Interval = Range where true DI likely falls

3. Statistical Significance (P-value & Effect Size)

📌 P-Value

Probability that the observed difference occurred by chance alone.

Threshold: p < 0.05 = Statistically Significant

p > 0.05: Not significant (likely due to random variation)

📌 Effect Size

Measures the magnitude of the difference (practical importance).

Small: 0.01-0.06

Medium: 0.06-0.14

Large: > 0.14

🔗 Combined Interpretation

A result can be statistically significant but small in effect (not practical)

A result can have large effect but not statistically significant (could be random)

🎯 In This Analysis

P-value > 0.05 for all metrics (not statistically significant)

Small effect sizes (0.0015 - 0.0672) indicate minor practical differences

4. Confidence Intervals (CI)

📌 What It Measures

Range of values where the true metric likely falls (95% confidence).

Formula: CI = Point Estimate ± Margin of Error

✅ Fair Threshold

For DI: CI should ideally fall within the fair range (0.80 - 1.25)

For SPD: CI should be close to zero

📊 Interpretation

Narrow CI: More precise estimate (larger sample)

Wide CI: More uncertain estimate (smaller sample)

CI crosses threshold: Uncertain fairness verdict

🎯 In This Analysis

Synthetic Gender DI: CI [0.68 - 0.97] (Fair, within range)

Kaggle Gender DI: CI [0.95 - 1.06] (Very fair, near 1.0)

🎯 What is Class Imbalance & Why We Use It?

Definition: Class imbalance occurs when one class (Strong) has far fewer examples than another (Weak). Real hiring systems have this naturally (33% qualified, 67% not qualified).

Why it matters for fairness:

  • ML models trained on imbalanced data bias towards the majority class (Weak)
  • This can amplify gender bias if gender is correlated with experience level
  • Example: If women are more likely to be entry-level (Weak), the model learns to reject them

The Solution: class_weight='balanced'

  • How it works: Upweights minority class (Strong) and downweights majority (Weak) during training
  • Weak weight: 0.7463 (multiply weak losses by 0.75x)
  • Strong weight: 1.5152 (multiply strong losses by 1.5x)
  • Effect: Model forced to learn Strong prediction equally well as Weak
  • Result: Both accuracy AND fairness improve!

Experience as a Strength Factor:

Three factors determine if candidate is Strong (35% weight each):

  1. Education (30%): PhD = 100%, Master = 80%, Bachelor = 60%, Bootcamp = 20%
  2. Experience (35%): Senior (8+y) = 100%, Mid (3-7y) = 67%, Entry (0-2y) = 33%
  3. Skills (35%): ML/AI focused = high, Cloud/Frameworks = medium, Languages alone = low

Example: Senior with Master's degree and TensorFlow experience → Strength score 0.85 → STRONG ✅

📋 Methodology & Fair-XAI Framework

Framework Architecture

This analysis uses the Fair-XAI Framework - a comprehensive, modular system for AI fairness auditing:

  • fairxai_data_loader.py: Loads CSV/XLSX with automatic column normalization
  • fairxai_fairness_metrics.py: Computes SPD, DI, confidence intervals, p-values
  • fairxai_explainability.py: Generates feature importance & SHAP values
  • fairxai_mitigation_strategies.py: Applies algorithmic bias reduction
  • fairxai_auditing_pipeline.py: Orchestrates full workflow

Statistical Methods

  • Wilson Score Interval: 95% confidence bounds for proportions
  • Two-Proportion Z-Test: Significance testing for differences
  • Cohen's h: Effect size to measure practical significance
  • Fairness Thresholds: Based on EEOC & policy standards
  • Type Handling: Automated null & data validation

Legal & Ethical Standards

  • Disparate Impact Rule (DI): 80% rule from EEOC
  • Statistical Parity (SPD): 10% policy guideline
  • Transparency: Full methodology documentation
  • Accountability: Clear fairness decision points
