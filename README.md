# AI Resume Analyzer - Backend Documentation

## Features
- **Resume Parsing:** Automatically extracts information from resumes in various formats.
- **Data Storage:** Saves parsed data into a structured database.
- **Search Functionality:** Supports searching for candidates based on extracted information.
- **API Integration:** Allows other applications to interact with the resume data through APIs.

## Installation Instructions
1. **Clone the repository:**  
   `git clone https://github.com/Aanya10Mishra/AI-Resume-Analyzer.git`

2. **Navigate to the backend directory:**  
   `cd AI-Resume-Analyzer/backend`

3. **Install dependencies:**  
   Use your preferred package manager to install the necessary packages. For example, with npm:
   ```bash
   npm install
   ```

4. **Set up environment variables:**  
   Create a `.env` file in the root of the backend directory:
   ```bash
   touch .env
   ```  
   Add required variables such as database connection strings and API keys.

5. **Run the application:**  
   ```bash
   npm start
   ```

## Setup Instructions
- Ensure that you have the required database system installed and running.
- Follow any additional setup instructions specific to the database you are using (e.g., MySQL, PostgreSQL).
- Configure the API routes as needed in the backend codebase.

> Note: This documentation focuses solely on the backend. For frontend instructions, please refer to the frontend documentation.
